
# Europe by Car – Online Car Rental Platform

Europe by Car is a fictional web-based car rental e-commerce platform developed as a portfolio project.

The application simulates an online vehicle rental process. Users can browse available vehicles, view detailed vehicle information, add vehicles to a shopping cart, enter rental and customer information, and complete a simulated booking.

## Main Features

- Vehicle Catalog
- Vehicle Details
- Search and Filter
- Shopping Cart
- Checkout
- Booking Confirmation
- AJAX interaction for adding vehicles to the cart
- Session-based shopping cart
- Server-side price calculation
- MySQL database
